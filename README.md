# Facial recognition project in *`Python`*

This is a project built **completely by me (and some youtube tutorials on how `AI` works).**
The main script that needs to be run is: ***`app.py`***, but the file with the facial recognition logic is: ***`faceid.py`***, which can be run separately as well.

**To run this project you will need the following libraries: *`opencv-python`, `face-recognition`, `torch`, `gradio`, `sentencepiece`* and *`tqdm`***

# More about *`PyBrain`* (and me)

In late 2025, AI started to become increasingly popular, and I challenged myself to build one myself **WITHOUT an API key (Application Programming Interface key)**. This lead me to create ***`PyBrain`***. Trained on **45GB (sourced from 🤗 https://hugingface.co) of training data, and an `AdamW` optimizer (Adaptive Moment Estimation with Weight decay)**, it was one of the biggest projects I made. Since this was developed merely to get an understanding of AI, and how it would react and respond, when trained **from scratch**, and how it would spot patterns within data, being trained in an Intel Iris (Xe) Graphics(R), and 8GB of VRAM (Video Random Access Memory). 

While it understands the general topic, such as **Science** if it is asked about atoms, but not always the more specific, **sub-topic**. This is due mainly to the fact that, depite its main training's data being about 44GB (which is quite a lot for a home-trained model), its context training (the data that trains it to stay context-focused), was only about 500MB. This would mean that the model did not have enough data to find big trends on how to stay on-topic. Due to techncal issues, I was unable to upload the model files, as they were too big, I can provide the file that runs the model.
